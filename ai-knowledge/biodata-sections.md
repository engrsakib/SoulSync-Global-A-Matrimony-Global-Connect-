# Biodata builder sections

Provisional mapping from Prisma models (refine when the matrimony PDF is attached).

**UI order** (see `BIODATA_SECTION_IDS`): `basic` → `faith` → `location` → `education_career` → `privacy` → `family_heritage` → `my_attributes` → `partner`.

| Section ID         | UI title                     | Model                                    | Fields                                                                                                                                                                                                                                                                                                       | Required (completeness)                   |
| ------------------ | ---------------------------- | ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------- |
| `basic`            | Personal details             | `Profile` + `MyPreference` (complexion)  | displayName, gender, dateOfBirth, heightCm, weightKg, bloodGroup, hasChronicConditions, chronicConditionsDetail, maritalStatus; optional `complexion` on `MyPreference`                                                                                                                                      | displayName, gender, dateOfBirth          |
| `faith`            | Religion & practice          | `Profile`                                | `religion` (default ISLAM for new profiles); `denomination` = branch code or free tradition; `religiousPractice` = Islam Sunni madhab code **or** practice notes; `community` optional. Catalog: `packages/shared-types/src/religion-branches.ts`                                                            | religion                                  |
| `location`         | Location                     | `Profile`                                | country, stateRegion, city, postalCode, motherTongue                                                                                                                                                                                                                                                         | country, city                             |
| `education_career` | Education & career           | `Profile` + `MyPreference` (income only) | degreeName, degreeMajor, institution, graduationYear, occupation, employer, yearsExperience, workLocation, bio (+ legacy `education` summary); optional `monthlyIncome`, `incomeCurrency` on `MyPreference` via same section PATCH                                                                           | degreeName or legacy education            |
| `privacy`          | Privacy & discovery          | `Profile`                                | photoVisibility, isDiscoverable, showContactOnlyToAccepted, hideFromContacts, guardianManaged                                                                                                                                                                                                                | —                                         |
| `family_heritage`  | Family heritage and identity | `Profile`                                | fatherIsAlive, motherIsAlive, fatherProfession, motherProfession, brotherCount, sisterCount, `familyRelatives` JSON (repeatable members), unclesOccupations, residenceDescription, familyEconomicClass (`FamilyEconomicClass` enum). Types: `packages/shared-types/src/family-heritage.ts`                   | —                                         |
| `my_attributes`    | About me (for matching)      | `MyPreference`                           | gender, complexion, heightCm, educationLevel, occupation, maritalStatus, monthlyIncome, incomeCurrency, residenceType, familyStatus, siblingCount, siblingPosition, district, country, religion, denomination, community, motherTongue, employmentTypes, willingToRelocate, openToAbroad, customExpectations | gender                                    |
| `partner`          | Partner preferences          | `PartnerPreference`                      | same as API `PartnerPreferenceDto`                                                                                                                                                                                                                                                                           | minAge, maxAge, preferredGender (derived) |

API: `GET /v1/biodata/me`, `PATCH /v1/biodata/me/sections/:sectionId`.

Encrypted-at-rest fields are listed in [biodata-encryption.md](./biodata-encryption.md).
